# Шарарам Live

Шарарам Live — альтернативный клиент для официального Шарарама. Игра, аккаунт и серверы те же: клиент подключается к shararam.ru и исполняет оригинальный игровой код. Разница в том, что вместо устаревшего Flash-плеера внутри Electron игра работает в современном эмуляторе Ruffle — поэтому меньше лагает и заметно слабее нагружает процессор и память. Но, конечно, может и иногда уступить в стабильности.

Играть можно двумя способами. Онлайн-версия на нашем сервере подходит, чтобы быстро убедиться, что всё работает: в этом режиме трафик, включая вход в аккаунт, проходит через наш сервер — по-другому онлайн-вариант устроен быть не может. Для постоянной игры скачайте приложение из Releases: оно целиком работает на вашем компьютере и общается с официальными серверами напрямую.
